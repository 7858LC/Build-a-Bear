# The Unseen Layer

> *"Uncovering what the text is really saying."*

## Overview

A specialized sermon preparation tool designed for **Black Baptist and evangelical preachers**. The Unseen Layer uses a set of unique **diagnostic lenses** to help ministers excavate deep theological insights buried within biblical texts — moving beyond surface reading into the layers of meaning that shape transformative preaching.

## Purpose

Most sermon software helps preachers organize what they already know. The Unseen Layer does something different: it helps them **discover what they don't yet see** — the hidden structural, cultural, and theological dimensions of a passage that can unlock a sermon's full power.

## Core Concept — Diagnostic Lenses

Each lens applies a distinct analytical framework to a biblical text:

| Lens | Focus |
|------|-------|
| Historical-Cultural | Original context, audience, and social world of the text |
| Theological | Doctrinal themes and their weight in the broader canon |
| Liberation | How the text speaks to freedom, justice, and the Black experience |
| Narrative | Story arc, characters, tension, and resolution |
| Prophetic | What the text demands of the preacher and congregation today |

## Design Language

| Element | Value |
|---------|-------|
| Theme | Dark mode |
| Background | Charcoal (`#1a1a1a` / `#2b2b2b`) |
| Accent | Amber (`#f59e0b` / `#d97706`) |
| Mood | Premium, reverent, focused |
| Typography | Serif for Scripture display, clean sans for UI |

The aesthetic is intentional — reverent and focused, designed to feel like a scholar's study rather than a productivity app.

## Target User

- Black Baptist preachers
- Evangelical ministers
- Seminary students preparing expository sermons
- Pastors seeking deeper exegetical tools

## Key Features (Planned / In Development)

- [ ] Scripture input with automatic text retrieval
- [ ] Diagnostic lens selector — apply one or multiple lenses
- [ ] AI-assisted insight generation per lens
- [ ] Sermon outline builder from lens findings
- [ ] Dark-mode UI with charcoal/amber design system
- [ ] Export to notes, outline, or manuscript

## Notes & Ideas

- The name "Unseen Layer" reflects the mission: revealing what is present but invisible to the casual reader
- Consider a "preacher's journal" feature for capturing Spirit-led insights mid-study
- The liberation lens is a distinctive differentiator — lean into it
